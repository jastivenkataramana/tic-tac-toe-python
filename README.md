# Tic-Tac-Toe Game in Python

A simple console-based Tic-Tac-Toe game developed in Python as part of the Cisco Networking Academy Python Essentials 1 project.

## Project Description

This project implements a simple Tic-Tac-Toe game where a user plays against the computer.

The computer uses `X` and the user uses `O`. The computer makes random moves, and the game checks for a win, loss, or tie.

## Features

- 3 × 3 Tic-Tac-Toe board
- Computer plays using `X`
- User plays using `O`
- Computer makes random moves
- User input validation
- Prevents moves on occupied squares
- Checks for winning combinations
- Detects a tie
- Console-based interface

## Technologies Used

- Python
- Python `random` module
- Lists
- Functions
- Loops
- Conditional statements
- User input handling
